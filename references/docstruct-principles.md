# DocStruct Principles

DocStruct keeps documentation useful for humans and AI agents.

- Write less documentation, but better documentation.
- Read before writing.
- Update existing docs before creating new files.
- Keep one source of truth.
- Separate docs by responsibility.
- Link instead of copying.
- Mark `TODO` and `UNKNOWN` clearly.
- Do not invent missing details.
- Avoid empty placeholder files.
- Avoid decorative documentation.
- Keep the next step clear.
