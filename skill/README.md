# DocStruct Skills

This folder contains reusable skill instructions for AI agents.

- `docstruct.skill.md` is the standard DocStruct skill. Use it when the agent has enough context budget to inspect, decide, and document carefully.
- `compact.skill.md` is the lightweight version. Use it when the agent needs low-token guidance or when the project is small.

Both files focus on documentation decisions: what to read, what to update, what to create, what to avoid, and how to preserve a single source of truth.
