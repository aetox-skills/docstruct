# AGENTS.md

## Documentation Behavior

Use DocStruct when creating, updating, auditing, or organizing project documentation.

Rules:

- Read existing docs and nearby source files before writing.
- Update existing docs before creating new docs.
- Create files only when they have clear responsibility.
- Keep one source of truth for each durable fact.
- Link instead of duplicating API, database, UI, or deployment details.
- Mark uncertain information as `UNKNOWN`.
- Mark required work as `TODO`.
- Keep documentation concise and practical.
- Do not create empty placeholder files.

Final rule: write less, but make the next step clear.
